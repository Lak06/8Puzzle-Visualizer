Depth Limited Search

Solver

Set the start and goal states, pick a depth limit, then run. Pause at any point and move one step at a time in either direction.

1 · Puzzle input

Type 1 to 8 once each. Leave one cell empty, or type _ or 0, for the blank.

A random puzzle is made by sliding tiles away from the goal, so it is always solvable. The shortest solution is at most the scramble length.

2 · Algorithm

This site implements the algorithm assigned to this registration number, Depth Limited Search.

Skips a state that is already on the current path or was already expanded at the same or a shallower depth. Turn it off to see plain tree-search DLS, which can generate far more nodes.
