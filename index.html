The 8-Puzzle Problem

Eight numbered tiles sit on a 3 × 3 board with one empty square. A move slides a tile next to the blank into it. The task is to turn a given start arrangement into a goal arrangement using as few, or at least some valid, moves.

As a search problem, a state is one arrangement of the tiles, the actions are Up, Down, Left and Right moves of the blank, every move costs 1, and the goal test compares the board with the goal state. Search algorithms explore the tree of states that grows out of the start state.

This site solves the puzzle with Depth Limited Search, a depth first search that stops going deeper once it reaches a chosen depth limit. You choose the start state, the goal state and the limit, then watch every node the search expands.

The search space

181,440reachable states from any start
362,880arrangements in total (9!)
2 – 4legal moves per state (branching factor)
31moves, the longest optimal solution

Only half of all arrangements can reach a given goal. The solver checks the inversion parity of the start and goal and tells you when no solution exists.
