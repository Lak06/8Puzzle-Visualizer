Algorithm 3 · Uninformed search

Depth Limited Search (DLS)

Depth first search with a ceiling on how deep it may go.

Description

DLS is depth first search run with a fixed depth limit l. The root has depth 0. A node at depth l is tested against the goal but never expanded, so the search cannot go down an infinitely long or very deep branch. It uses no knowledge about the goal, which makes it an uninformed search.

Working principle

  1. Put the start node on a stack.
  2. Pop the top node. If it is the goal, stop with a solution.
  3. If its depth equals l, record a cutoff and do not expand it.
  4. Otherwise generate its successors and push them so the first one is explored next.
  5. Repeat until the stack is empty. Report cutoff if any branch was cut, otherwise failure.

Advantages

  • Very low memory, only the current path and its siblings.
  • Never loops forever on deep or infinite branches.
  • Simple to implement with a stack.
  • Fast when the goal lies within a shallow limit.

Limitations

  • Misses the goal if it is deeper than l.
  • A good limit must be guessed, or found by trial.
  • May return a long path even when a shorter one exists.
  • Without repeated-state checks it re-expands the same boards many times.

Properties

O(bl)Time complexity, b = branching factor, l = depth limit
O(b·l)Space complexity
If l ≥ dCompleteness: complete only when the shallowest goal depth d is within the limit
NoOptimality: the first solution found is not guaranteed to be the shortest

Pseudocode

function DLS(start, goal, l):
    stack ← [ (start, depth 0) ]
    cutoff ← false
    while stack is not empty:
        node ← stack.pop()
        if node.state = goal: return SOLUTION(node)
        if node.depth = l:
            cutoff ← true          # do not expand
        else:
            for each move in [Up, Down, Left, Right]:
                child ← apply(move, node)
                stack.push(child)  # first move on top
    return cutoff ? CUTOFF : FAILURE

On the 8-puzzle

  • The blank has 2, 3 or 4 moves, so b is about 2.7 on average and at most 4.
  • Moves are tried in the order Up, Down, Left, Right, which sets the order of the search.
  • The 5-move example from the assignment needs l ≥ 5. With l = 4 the search returns a cutoff.
  • Every move costs 1, so the path cost g(n) equals the node depth.
  • The Skip repeated states option keeps DLS complete for its limit while stopping it from re-expanding boards it has already seen at the same or a shallower depth.

No heuristic is used. Misplaced Tiles and Manhattan Distance apply to informed searches (GBFS and A*), which are not part of this assignment.
